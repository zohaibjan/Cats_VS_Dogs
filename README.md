# Cats vs Dogs Image Classification

A PyTorch learning project for training a convolutional neural network on the Kaggle Dogs vs Cats dataset.

## Setup

1. Obtain the dataset separately from Kaggle and follow its usage terms.
2. Install a Python environment compatible with the imports in `mainFile.py`.
3. Update the training and test paths in the script. The original paths are:

```text
dogs-vs-cats\train
dogs-vs-cats\test1
```

4. Review the data-preparation flag. If the processed dataset is already built, set `REBUILD = False` as appropriate.
5. Run `python mainFile.py`.

## Scope

An educational CNN experiment. Model accuracy, dataset splits and compatibility have not been revalidated as part of this documentation update.
